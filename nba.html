PowerBI - NBA Dashboard

View GitHub Repository

Dashboard Default

Dashboard looks into the NBA stats from 2020 - 2024 seasons, both regular season and playoffs. Showcasing the top players for different statlines as well as Team performance through the years.

-Scrapped data from the NBA website using Python, Anaconda and Pandas.
-Used MySQL to create queries and clean up the data.
-In SQL, using views for the season type, and case statements for conference.
-DAX queries created on the dashboard to display the top and bottom teams as well as their logo.
-user can select between the regular season or playoffs, East or West conference, as well as which season (2020 - 2024).


Different filters applied to the data, showcasing different team graphics appearing based on stats


Data Scrape: https://www.nba.com/stats
Team Logos: https://www.sportslogos.net/


Scraped using Python (Jupyter Notebooks), Pandas and NumPy libraries


MySQL used to create independent views as well as labelling the teams in proper conferences


DAX code to display top teams
